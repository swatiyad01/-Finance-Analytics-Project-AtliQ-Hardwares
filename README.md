# 📊 Finance Analytics Project – AtliQ Hardwares

## 📌 Project Overview
This project focuses on analyzing business performance using P&L reports across multiple dimensions including Years, Months, Markets, and Subzones.

---

## 🔍 Key Insights

- Net Sales grew from $196.7M to $598.9M (204% growth)
- Gross Margin % declined (41.4% → 36.4%), indicating cost pressure
- Growth was consistent across months with multiple high-growth spikes
- YoY comparison showed strong growth across months (150%–400%+)
- India generated the highest revenue with moderate GM% (~32%)
- Profitability varied across subzones (~32%–42%+ GM%)

---

## 📚 Key Learnings

- Built dynamic P&L reports (Yearly & Monthly)
- Performed time-based & regional analysis
- Strengthened understanding of financial KPIs

---

- Microsoft Excel
- Power Query
- Pivot Tables
